1. 前後都有兩個底線:__xxx__(唸作 "dunder",double underscore 的縮寫)

這是 Python 或框架保留給「有特殊意義」的名稱,不是你自己隨便取的一般變數。你已經看過好幾個例子:

- __init__:class 的建構子(初始化方法),Python 語言本身認得這個名字,new 一個物件時會自動呼叫它
- __name__:每個 Python 檔案內建的變數,代表這個檔案的模組名稱(你可能看過 if __name__ == "__main__": 這種寫法)
- __tablename__:這個不是 Python 內建的,是 SQLAlchemy/SQLModel 這個框架自己規定的特殊屬性名稱——框架的程式碼裡面會去檢查你的 class 有沒有寫這個名字,如果有,就拿它當 table 名稱用

規則是:這種 __xxx__ 格式,是「跟語言或框架有約定」的保留名稱,你自己寫一般變數/函式時不要模仿這種命名方式,除非你是在故意實作某個 Python 認得的特殊行為(進階用法,現階段用不到)。

2. 只有開頭一個底線:_xxx

這是開發者之間的默契/暗號,代表「這是內部用的東西,外部不要直接使用」,但 Python 不會真的強制擋住你,純粹是禮貌性的提醒。例如 _internal_helper() 暗示「這是給這個模組內部自己用的函式,你在外面 import 別亂用」。

3. 開頭兩個底線,結尾沒有:__xxx(只在 class 內部使用)

這個比較少見,是 Python 真的會做「改名」處理(叫 name mangling),讓這個屬性變得比較難從 class 外面直接存取到,算是比較強的封裝手法,初學階段可以先不用管,遇到再說。

你現在需要記住的重點:__init__.py(檔名)、__init__(方法名)、__tablename__ 都是格式 1——看到這種前後雙底線的名字,代表「這是 Python 或某個框架認得的特殊名稱」,不是隨便取的,要照規定的拼法寫,不能自己改名字(例如不能寫成 __table_name__,SQLAlchemy 只認 __tablename__ 這個確切拼法)。
